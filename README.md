# Hidden Yeongdo – tourism website (student project)

Static multi-page site for GitHub Pages: HTML + CSS + vanilla JavaScript.

## Pages
- `index.html` – hero, three destination cards, sunset widget
- `about.html` – story, team, values
- `packages.html` – 1-Day tour with clickable hour-by-hour timeline
- `gallery.html` – filterable photo gallery, lightbox, media, OpenStreetMap (Leaflet)
- `contact.html` – booking form with JavaScript validation (simulated submit)

## Before the final presentation
1. Replace the dummy images in `images/` with your own photos (keep the same file names, or update the `src`).
2. Fill in `[Name 1/2/3]`, `[₩__,000]` and `[Address]`.
3. Check the map coordinates in `js/main.js` (part 7) on openstreetmap.org.

## Deploy on GitHub Pages
Push this folder to a repository → Settings → Pages → Deploy from branch `main` / root.
